# หน้าเล่นเกมบนโต๊ะกลม

13 ตุลาคม 2026 ผู้ใช้อนุมัติให้ลงมือจากข้อเสนอ: ใช้โต๊ะไม้กลมต่อจากล็อบบี้ ไพ่และปุ่มของเราใต้โต๊ะ กลางโต๊ะแสดงพ่อค้าที่ถูกเลือก กระเป๋า และผลที่เปิดเผยได้ ใช้สี/ฟอนต์/ตัวละครเดิมจาก home.html

- ตัวเองอยู่ล่างเสมอ รวมเมื่อเป็นนายด่านและมีป้ายนายด่าน เมื่อคนอื่นเป็นนายด่านจะอยู่ตรงบนของโต๊ะ ทั้ง4/5/6คน
- เมื่อเปลี่ยนนายด่าน สลับเฉพาะที่นั่งบนกับคนใหม่โดยตรึงเราไว้ เมื่อเราเป็นนายด่านเองคงที่นั่งทุกคนไว้ แสดงป้ายที่เรา เมื่อส่งต่ออีกครั้งสลับที่นั่งบนกับคนใหม่ตามเดิม ไม่เปลี่ยน seatOrder/ลำดับเทิร์นจริง
- เก็บตำแหน่งภาพก่อนหน้าในmemoryของหน้าที่เปิดอยู่เพื่อขยับไม่เกิน2คน เมื่อreloadจัดภาพใหม่จากผู้เล่นปัจจุบัน โดยยังให้เราอยู่ล่างและนายด่านคนอื่นอยู่บน server seatOrderและที่นั่งผู้เล่นจริงคงเดิม
- ไอคอนอ่าน avatarId ที่เลือกจริง แสดงชื่อ/เงิน/สถานะ/คำแจ้งที่serverอนุญาตให้เผย พร้อมเน้นพ่อค้าที่ถูกเลือก มีขั้นตอนของรอบและปุ่มข้ามไปไพ่/ปุ่มของตัวเอง
- เงินคงเหลือใต้ชื่อทุกคนใช้ป้ายพื้นครีม ขอบหนังบางและรอยเย็บ ไอคอนเหรียญ ตัวเลขเข้มตัวหนา18pxบนมือถือ/20pxบนจอใหญ่ และหน่วยเหรียญขนาดเล็ก ป้ายของเราเพิ่มขอบทอง อ่านยอดเดิมจากpublic player.cashทุกช่วงหลังเริ่มเกม รวมเมื่อเป็นนายด่าน/จบเกม ป้ายข้อเสนอยังคงคำว่าเสนอและพื้นทองแยกกัน มีข้อความเงินคงเหลือสำหรับscreen reader ปรับระยะโปรไฟล์และพื้นที่ใต้โต๊ะให้ป้ายไม่ทับชื่อ คำแจ้ง สถานะ ข้อเสนอหรือพื้นที่ไพ่ ผลตรวจ [cash badges](../work/verification/cash-badges/report.md)
- โต๊ะและข้อมูลกลางโต๊ะใช้จุดกึ่งกลางเดียวกับวงผู้เล่น โปรไฟล์ยึดกึ่งกลางของทั้งบล็อกที่รวมรูป ชื่อ เงินและสถานะ แทนยึดเฉพาะรูป เพื่อไม่ให้โต๊ะดูเยื้องหลังเพิ่มป้ายเงิน รัศมีแยกตามพื้นที่/ช่วงข้อเสนอ แต่จุดกลางร่วมกันทุกช่วงและทุกมุมมอง คงlayoutแบบไหลเมื่อจอแคบมาก/ขยายข้อความ ผลตรวจ [table centering](../work/verification/table-centering/report.md)
- ไพ่/เลือกแลก/จัดกระเป๋า/แจ้งสินค้า/เสนอเงิน/เลือกพ่อค้า/ยืนยันตรวจหรือให้ผ่าน/สรุปรอบ ใช้ MerchantControls และ SheriffControlsเดิมผ่านcallbacksเดิม Draft/retry/offline/read-only/control takeoverคงเดิม
- นายด่านบนมือถือใช้SheriffDecisionPanel/native popupแทนกล่องเลือกพ่อค้าที่ต้องเลื่อนลงไปหา เปิดอัตโนมัติเมื่อเริ่มเจรจา รายชื่อแรกมีเฉพาะชื่อ/โปรไฟล์ของคนที่ยังไม่ถูกตัดสิน กดคนแล้วรอยืนยันselectMerchantจากserverก่อนแสดงชื่อ/รูป คำแจ้ง ข้อเสนอล่าสุด และปุ่มให้ผ่าน/ตรวจ ย้อนกลับรายชื่อหรือปิดเพื่อดูโต๊ะได้ มีปุ่มเปิดซ้ำลอยเหนือsafe area ปิดแล้วล้างการยืนยันที่ยังไม่ได้ส่ง ผลตัดสินและคำสั่งคนถัดไป/สรุป/จบรอบอยู่ในpopupต่อเนื่องโดยใช้callbacksและversion guardsเดิม สรุปผลอ่านเฉพาะpublic resultและใช้ข้อความเดียวกับกล่องผลเดิม PASSไม่เผยชนิดไพ่ Desktopยังใช้panelในหน้า รายชื่อเพิ่มโปรไฟล์เหมือนกัน รองรับมือถือแนวนอนที่มีtouch ข้อความ200% keyboard/escape/focus trap และสถานะretry/control takeoverในpopup Previewเลื่อนมาที่iframeเมื่อpopupใหม่เปิด มีcleanupของmedia/DOM observers ผลตรวจ [sheriff popup](../work/verification/sheriff-popup/report.md)
- Popupนายด่านอยู่กึ่งกลางหน้าจอทั้งหน้าเกม/ตัวอย่างเต็มหน้า/Previewแบบฝัง ไม่มีoverrideชิดบน เมื่อมีpopupนายด่านในPreviewกรอบสูงเท่าหน้าจอผู้ชมและปรับเมื่อresize แม้ปิดชั่วคราวยังคงviewportนี้เพื่อให้เปิดซ้ำตรงกลาง เฟสอื่นยังขยายกรอบตามเนื้อหาเหมือนเดิม ผลตรวจ [popup centering](../work/verification/sheriff-popup-center/report.md)
