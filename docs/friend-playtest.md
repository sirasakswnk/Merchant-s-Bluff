# เล่นกับเพื่อน

## เริ่มเกมใหม่บน Production

1. ทุกคนเปิด **[merchant-s-bluff.vercel.app](https://merchant-s-bluff.vercel.app)** ในSafari/Chrome/Edge ไม่ต้องมีบัญชีVercelหรือเปิดshare linkก่อน
2. คนหนึ่งกรอกชื่อเล่น เลือกอวาตาร์ แล้วกด **สร้างห้องและเข้าเล่น**
3. ส่งรหัสห้อง4ตัวหรือลิงก์ห้องให้เพื่อน คนอื่นกรอกชื่อเล่นและเข้าห้อง
4. เมื่อครบ4–6คน ทุกคนกด **พร้อม** แล้วเจ้าของห้องกด **เริ่มเกม**
5. ใช้browserเดิมตลอดเกม Refreshรองรับกลับที่นั่งเดิม การเปลี่ยนbrowser/ล้างstorageอาจทำให้เป็นผู้เล่นใหม่

ถ้ามีเกมค้างในPreviewเดิมให้เล่นจบที่ลิงก์เดิม แล้วเริ่มห้องใหม่บนProduction บัญชีAnonymousแยกตามorigin แม้ใช้Firebaseชุดเดียวกัน ผลตรวจreleaseอยู่ [รายงานProduction](../work/verification/production-release/report.md) ระบบล้างห้องอัตโนมัติยังปิด

## ลิงก์ Preview เดิมสำหรับเกมที่เริ่มไว้

ลิงก์จากแชท/ไฟล์ส่วนตัวเดิมยังอยู่และหมดอายุ **19 ตุลาคม 2026 เวลา14:37น. (ไทย)** ผูกกับdeploymentก่อนเพิ่มretention ส่งให้กลุ่มผู้ทดสอบที่เลือกเท่านั้น ไม่ใส่ลิงก์เต็มในrepoสาธารณะ ขั้นตอนส่วนนี้ใช้เฉพาะPreviewเดิม

### เข้า Preview เดิม

1. ส่ง **ลิงก์ทดสอบจากแชท** ให้ทุกคน เปิดด้วยSafari/Chrome/Edgeบนเครื่องที่จะใช้เล่น ไม่ต้องมีบัญชีVercel
2. คนหนึ่งกรอกชื่อเล่น เลือกอวาตาร์ แล้วกด **สร้างห้องและเข้าเล่น**
3. ส่งรหัสห้อง4ตัวให้เพื่อน คนอื่นเปิดลิงก์ทดสอบก่อน แล้วกด **เข้าด้วยรหัส** กรอกรหัสและชื่อเล่น
4. เมื่อครบ4–6คน ทุกคนกด **พร้อม** แล้วเจ้าของห้องกด **เริ่มเกม**
5. เล่นบนbrowserเดิมตลอดเกม ทุกคนเป็นนายด่านคนละ2ครั้ง: 4คน8รอบ / 5คน10รอบ / 6คน12รอบ

ทุกคนต้องเปิดลิงก์ทดสอบอย่างน้อยครั้งแรกก่อนใช้ลิงก์ห้องที่คัดลอกจากเกม รหัสห้องอย่างเดียวไม่ได้ให้สิทธิ์ผ่านหน้าVercel Protection หากเจอหน้าVercel login ให้กลับมาเปิดลิงก์ทดสอบเต็มจากแชทอีกครั้ง

หากเปิดจากแอปแชทแล้วจะเปลี่ยนไปSafari/Chrome ให้เลือกbrowserก่อนสร้าง/เข้าห้อง การเปลี่ยนbrowserหรือการล้างstorageอาจทำให้เป็นผู้เล่นคนใหม่ Refreshในbrowserเดิมรองรับการกลับที่นั่งเดิม

## ระหว่างเกม

- เตรียมสินค้า: เลือกไพ่ที่จะแลกได้ตามกติกา แล้วกด **พร้อมจัดกระเป๋า**
- จัดกระเป๋าและแจ้งสินค้า: เลือกไพ่1–5ใบ แจ้งสินค้าถูกกฎหมายหนึ่งชนิด แล้วยืนยัน จำนวนจริงเติมให้อัตโนมัติ
- เจรจา: เสนอเงินหรือกด **ไม่เสนอเงิน** คุยกันผ่านแอปที่กลุ่มใช้อยู่
- นายด่านเลือกพ่อค้าได้อิสระ กดตรวจ/ให้ผ่านและยืนยัน ทุกการเดินรอบต้องกดเอง ไม่มีcountdownหรือauto-pass
- เมื่อขึ้นผลแล้ว นายด่านกดเลือกคนต่อไป/สรุปรอบ และกดจบรอบเพื่อส่งตำแหน่ง
- ถ้าเน็ตหลุด รอเชื่อมต่อก่อนส่งคำสั่ง ถ้าขึ้นว่ายังยืนยันผลไม่ได้ให้กด **ลองคำสั่งเดิมอีกครั้ง** ก่อนส่งคำสั่งอื่น

เกมใหม่ใช้360ใบ/rulesVersion0.2 ราคา ค่าปรับ ค่าชดเชยและกติกาเดิมทั้งหมด เกมเก่าคงsnapshotเดิม ลิงก์Previewเดิมหมดอายุเป็นการจำกัดการเข้าPreview ไม่ใช่ตัวจับเวลาของเกม URLหลักProductionไม่ต้องใช้share tokenนี้

## ชุดทดลองของกลุ่ม

เริ่มด้วย4คนหนึ่งเกมเต็ม8รอบเพื่อดูว่าคนใหม่เข้าใจทุกขั้นตอนได้ แล้วแยกนัด5/6คนถ้าพร้อม ลองทั้งตรวจของถูกกฎหมายผสม ตรวจของต้องห้าม ให้ผ่านพร้อมเงินเสนอ และให้ผ่านโดยไม่เสนอเงิน อย่าล็อกให้ทุกคนใช้กลยุทธ์เดียวในการวัดความสนุก/สมดุล

สำหรับstress testแยกอีกเกม ใช้ขน5ใบและPASSตลอด ทั้งไม่แลกและแลก3ทุกครั้ง ถ้าพบปัญหาต้องเก็บผลให้ตรวจ ไม่ปรับราคา/กติกาเพื่อทำให้ผลดูดี

## บันทึกผลหลังเกม

คัดลอกแบบนี้แล้วส่งกลับในแชท ไม่ต้องส่งcredentials, private key หรือlink token

```text

มือถือหรือคอม / รุ่น / browser:
จบเกมได้หรือไม่ / ติดที่รอบและเฟสใด:
คะแนนและผู้ชนะ:
ขั้นตอนหรือคำอธิบายที่เข้าใจยาก:
ปุ่ม/ข้อความที่ถูกบังหรือกดยาก:
การหลุด/refresh/retry และผลที่เห็น:
จำนวนครั้งที่ตรวจ / ให้ผ่าน / เสนอเงิน (ถ้านับได้):
ความสนุก 1–5 / ระยะรอที่รู้สึกนาน:
ข้อสังเกตเรื่องสมดุล (ยังไม่เปลี่ยนราคา):
ปัญหา: ทำอะไร → คาดหวังอะไร → เกิดอะไรจริง

```
