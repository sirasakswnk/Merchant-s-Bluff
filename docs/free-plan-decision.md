# ใช้แผนฟรีสำหรับเล่นกับเพื่อน

วันที่ 12 ตุลาคม 2026 ผู้ใช้เลือกข้ามการคำนวณค่าใช้จ่าย เพราะสร้างเว็บไว้เล่นกับเพื่อนและใช้แผนฟรี ให้คงการตัดสินใจนี้ในการพัฒนาขั้นถัดไป

- Vercel: ตรวจ team ที่ผูกกับโปรเจกต์แล้วเป็น Hobby สถานะ active
- Firebase: ผู้ใช้ยืนยันว่าใช้แผนฟรี ไม่ได้ยืนยันแพ็กเกจหรือยอด usage จาก billing API
- ยุติงานคำนวณต้นทุนต่อเกมและการเปรียบเทียบแพ็กเกจ ไม่ถือว่าตรวจยอด usage แล้วหรือมีหลักฐานค่าใช้จ่ายเป็นศูนย์
- ไม่มีการอัปเกรดแพ็กเกจ เปิด billing เพิ่มสิทธิ์ service account หรือเปิด Production/Cron ในขั้นนี้

ผลตรวจที่ทำก่อนผู้ใช้เลือกข้าม: Vercel CLI ไม่มีข้อมูลบิลของช่วงปัจจุบัน และ metrics query ต้องใช้ Observability Plus; Firebase billing/monitoring API อ่านไม่ได้ด้วยสิทธิ์ปัจจุบัน ไม่ซื้อบริการหรือเปลี่ยนสิทธิ์เพื่ออ่านตัวเลขเหล่านี้

ขั้นเตรียม environment ถัดมาผู้ใช้อนุมัติให้ใช้ Firebase `merchant-s-bluff` ร่วมกับ Preview สำหรับเว็บเล่นกับเพื่อน จึงแยกเฉพาะ Vercel environment scopes โดยใช้ Auth/RTDB ชุดเดียวกันตามข้อยกเว้นนี้ คงแผนฟรี การเตรียม environment และการเผยแพร่เป็นคนละขั้น กติกา ราคา สำรับ 360 ใบ และงานดีไซน์ยังคงตามที่อนุมัติไว้ ดู [Production setup](production-setup.md)
